# Статистика и публикация

## Локальный запуск

```bash
npm install
npm run dev
```

Проверить итоговую сборку можно командой `npm run build`. Готовый статический сайт появится в папке `dist`.

## Статистика посещений и PDF

Сайт подготовлен для Яндекс Метрики. До настройки счётчика никакие данные не отправляются.

1. Создайте счётчик в [Яндекс Метрике](https://metrika.yandex.ru/) для домена сайта.
2. Скопируйте `.env.example` в `.env.local` и укажите полученный числовой ID:

   ```env
   VITE_YM_COUNTER_ID=12345678
   ```

3. Пересоберите сайт: `npm run build`.
4. В Метрике включите автоматические цели. Посещения появятся в стандартных отчётах, а клики по PDF — в «Отчёты → Содержание → Загрузки файлов».
5. Если нужен отдельный счётчик кликов по портфолио-документам, создайте цель типа «Целевое событие» с идентификатором `portfolio_pdf_open`.

Метрика фиксирует клик/попытку открыть файл, но не может подтвердить, что браузер завершил загрузку. Когда появится отдельный PDF резюме, добавьте его в `src/assets` и сделайте на него ссылку: его клики будут определяться так же.

## Публикация на платном хостинге

Сайт статический, поэтому ему не нужны сервер, база данных или VPS. Подойдёт обычный виртуальный хостинг с HTTPS и возможностью загрузить файлы в папку сайта.

1. Купите домен и виртуальный хостинг у выбранного провайдера.
2. В панели хостинга добавьте домен и включите бесплатный SSL-сертификат Let's Encrypt.
3. На своём компьютере создайте `.env.local` с ID Метрики и выполните `npm install`, затем `npm run build`.
4. Загрузите **содержимое** папки `dist`, а не саму папку, в корневую папку сайта (часто `public_html`, `www` или `htdocs`).
5. В панели домена укажите DNS-серверы хостинга или A-запись, как требует провайдер. Дождитесь обновления DNS и откройте домен по HTTPS.
6. Откройте сайт в режиме инкогнито, проверьте ссылки и в Метрике убедитесь, что счётчик получает визит.

Для Timeweb Cloud ничего дополнительно менять не нужно: сборка рассчитана на корень домена. Для GitHub Pages в подкаталоге `/resume/` задайте при сборке `VITE_BASE_PATH=/resume/`.
